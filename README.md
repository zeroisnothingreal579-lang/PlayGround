## Click Lab — safe archive recreation

The attachment is a Windows payload bundle (`BotOpener.exe`, `ADFly.sys`, `termdd.sys`) with no application source. It was inspected statically and **not executed**. Instead, this repository contains a self-contained, browser-only simulation of the advertised dashboard: queued links, virtual relays, credit rates, earnings, an event stream, and a campaign report. It never opens links, contacts a network, or installs anything.

- `index.html` — dashboard shell
- `styles.css` — dark telemetry theme
- `app.js` — campaign simulation, canvas mesh, earnings chart, and archive analysis dialog

Open `index.html` directly, or run `./start.sh` with the OMGithub runtime to serve it locally.
